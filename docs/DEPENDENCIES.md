# Dependency manifest

| Dependency | Pinned source | License | Current use/status | Notes |
|---|---|---|---|---|
| Wicked Engine | [upstream](https://github.com/turanszkij/WickedEngine), commit `4f93f3fd4f337aeb38dbfe410701b83024ccdd42`, Git submodule `third_party/WickedEngine` | Upstream repository: MIT. Its `third_party_software.txt` and bundled component notices remain applicable. | First renderer candidate. The app builds the engine library and the pinned `Editor/ModelImporter_GLTF.cpp` source. | Lua 5.4.8 | Bundled under `third_party/WickedEngine/WickedEngine/LUA`; built through Wicked Engine's `LUA` target | PUC-Rio MIT-style copyright notice is present in the Lua headers; retain the Wicked Engine submodule and its bundled source notices. | OpenRepublic's separate `OpenRepublicScripting` library provides an isolated, validated data/rule loader. No system Lua executable is required. | The current app exposes no general-purpose Lua mod API: it accepts a narrow rule table, no standard libraries or engine APIs, text-only input, a 64 KiB source limit, an 8 MiB Lua-state allocation limit, and an instruction limit. |
| OpenRepublicContent | OpenRepublic-authored C++17 library in `src/content` | OpenRepublic MIT | Bounded legacy 2D DDS R32F reader and syntactic parser for five observed terrain metadata keys; shared by client and headless tests. | It does not implement general DDS, NMF, materials, world placement, or verified height/row semantics. |

No other third-party source, SDK, binary, or game asset is included in the public repository. A portable Blender 5.2.2 tool and an unlicensed community NMF add-on archive are kept in private research storage. The add-on was run once as a script against a copied local model in a background Blender process; it is not installed as a general Blender add-on or included here. Build outputs live in ignored local directories and are not committed.
