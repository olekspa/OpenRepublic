# Headless checks

Run the regular Release build, CTest suite, and every shipped synthetic economy
scenario twice with matching score hashes:

```powershell
./tools/run_all_checks.ps1
```

The script configures `build/headless` with the Wicked Engine client disabled,
builds Release, runs CTest, then scores every `data/scenarios/*.json` fixture at
600 ticks by default. It prints one compact row per scenario and stops on the
first configure, build, test, scorer, or repeat-hash failure. Pass
`-ScenarioTicks N` to change the scorer horizon or `-BuildDirectory PATH` to use
another headless build directory.

If the optional host is disabled because its pinned JSON dependency is missing,
pass `-HostExecutable PATH` to an already built `OpenRepublicEconomyHost.exe`.
That host's source revision is part of the evidence for scenario results; the
script does not establish that an external executable matches this checkout.

## Bounded reader robustness

`OpenRepublicBoundedReaderRobustnessTests` runs a deterministic corpus through
the road network, map header prefix/fixed-block, worker framing, building
placement framing, legacy R32F/RGBA8 terrain readers, terrain metadata parser,
building-definition parser, and catalog importer option validation. It walks
every truncation length of a 320-byte seed and of minimal complete road, map
header, and worker framing examples, flips each bit at 128 byte offsets, and
exercises large count sentinels. Failure paths must preserve caller output;
the focused tests also retain format-specific fixtures and boundary checks.
The generated bytes are synthetic test inputs and do not encode WRSR semantics.

The catalog importer consumes parsed C++ definitions rather than a byte stream;
its deterministic robustness coverage therefore targets invalid options and
transaction/diagnostic behavior. `SampleTerrainHeight`, terrain blend helpers,
and path-based DDS reads are value/path APIs and remain covered by their focused
tests rather than this byte mutation loop.

## Thread-count determinism

`Economy` test runs a synthetic production-heavy world above the parallel
threshold and compares its canonical state hash and building count at 1, 2, 4,
and 8 production threads. The all-scenario script separately checks repeat
score hashes for each shipped fixture using the normal host configuration.
These are OpenRepublic synthetic determinism checks; they do not establish WRSR
economy parity. Cross-thread execution of every scenario fixture through the
host is not currently part of the scorer path.
